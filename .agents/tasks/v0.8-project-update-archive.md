## Requirements

### Project model

Add this field to the Project model:

```python
is_archived = Column(Boolean, default=False, nullable=False, index=True)
```

Also make sure `Boolean` is imported from SQLAlchemy.

### Project update

Add a `ProjectUpdate` schema.

Fields should be optional:

```text
name
description
client_name
status
budget
start_date
deadline
```

Do NOT include `is_archived` in `ProjectUpdate`.

Archive must be handled only through the archive endpoint.

### Project response

Add `is_archived` to `ProjectResponse`.

### Repository

Add repository functions for:

```text
update_project
archive_project
```

Modify project listing:

```text
GET /api/projects should exclude archived projects by default.
GET /api/projects?include_archived=true should include archived projects.
```

### Service

Add service functions for:

```text
update_my_project
archive_my_project
```

All functions must verify ownership through `current_user.id`.

If a project does not exist or does not belong to the current user, return:

```text
404 Project not found
```

### Routes

```text

PATCH /api/projects/{project_id}/archive
```

Modify:

```text
GET /api/projects
```

to support:

```text

```

All project endpoints must stay protected with `get_current_user`.
